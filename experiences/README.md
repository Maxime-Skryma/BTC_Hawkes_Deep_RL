# Local experiment artifacts

Generated scores, selections, protocols and checkpoints are stored here. They are excluded from Git; a fresh clone contains this README only.

Run the [reproduction pipeline](../docs/reproduction.md) to generate the baseline inputs, synthetic checkpoints, historical grid, confirmation runs and final test. `final_selection/` holds selections, `final_test/` holds test outputs, and the other subdirectories hold intermediate experiment records.

Presentation exports belong in `../resultats/`. Historical snapshots are provenance records, not current executable commands.
